# Explicit authorized video intervals in native Short/Reel treatments

The catalog's normalized local videos can now supply an explicit visual interval
for a Short/Reel beat. This is owner selection, not semantic footage search or
channel downloading. Image/carousel/manual campaigns still require stills or
original graphics. Audio assets cannot be selected as visuals. Source audio is
excluded; the existing separate narration supplies the soundtrack.

The owner chooses an indexed asset, numeric start/end and an intentional hold
or loop treatment. Intervals must be 0.25–12 seconds, within the retained indexed
duration. No interval or end treatment is filled automatically. An incompatible
mixed-format campaign is blocked in both UI and API. A rendered export retains
the original/normalized source provenance, exact selected range, source hash,
actual silent-excerpt hash/duration, presentation duration and chosen treatment.

Each source frame is fitted in the card's 810×440 inset with padding rather than
cropping away source content. The poster uses that same framing. The original
card's title, body text and footer remain visible. Narration readability can make
a beat longer than its selected source: hold clones its final frame; loop repeats
only that selected interval. Nothing extends the source range or trims narration.
The complete actual export still requires decode/audio/duration/inspection gates.

Every extended hold/loop produces a distinct editorial finding requiring a
substantive decision at exact-export acceptance. Repeated source-asset selections
also remain explicit findings. The owner must inspect framing, full motion,
narration/caption meaning, transitions and rights; the app has not established
those qualities by retaining hashes or passing decode. Changes to intervals,
source/provenance, inspection or treatment invalidate current input/approval.

Rendering holds shared renewable claims on all selected source paths and its
unique output root, rechecks inputs after acquiring claims, and rechecks again
before promoting an export. Cooperating mutation/cleanup cannot replace a source
in use. An out-of-band change is detected before promotion. Retained silent
excerpts are hash-checked at later review/queue/download/publication admission,
not merely trusted because the final mux still exists. Failed attempts preserve
their local evidence and cannot create a successful export row.

The new local contract tests render actual hold and loop outputs from original
procedural moving footage, compare delivered inset frames, probe video-only
excerpts and measure the actual final audio's two known fixture frequencies to
check source-audio exclusion. Separate tests cover strict bounds/missing choices,
unsupported formats, independent conflicting file claims, changed-source failed
promotion and retained-excerpt corruption. Synthetic tones stand in for narration
in those unit contracts; this is not speech quality proof. Browser verification
uses actual UI/import, explicit interval selection, installed offline speech,
complete rendering, review findings and a review-only queue entry. See the current
progress ledger for completed evidence before counting a verification run.

Still open: independent semantic retrieval/identity, broader recut compositions,
word-aligned captions, compatible owner-authorized music/audio treatments,
preservation of original-resolution masters, excellent real-content examples and
actual provider delivery. No borrowed source media, paid API, live account or
public posting is needed for these local contracts. The Shorts archive and Drive
authentication remain deferred by the owner.
