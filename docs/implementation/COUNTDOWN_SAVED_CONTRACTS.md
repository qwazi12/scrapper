# Saved Countdown recovery and current segment admission

Older saved lists remain readable. They cannot inherit current title eligibility,
intro/outro review or export acceptance. Only exact integer contract version1
admits current work; missing/version0 lists require an explicit recovery draft.
Future or malformed versions remain unsupported and cannot be downgraded here.

The **Saved Countdown needs fresh review** form sends an owner acknowledgment
with the complete saved-context digest, including source creation identity,
ranking, words, render, review and links. A concurrent edit or recycled identity
rejects the request. Active parent/child leases and media readers protect ongoing
work. The recovery transaction retains original export inputs/media and an undo
record, keeps script/ranking/private notes, clears unproven child links, render
readiness and acceptance, and creates a current review draft. It does not fetch
providers, voice words, certify old files or enqueue/publish anything.

The owner repairs the requested entry count, canonical titles and editorial
rationales, then confirms current category/territory/date/provider eligibility.
Confirmation creates campaign-owned segments and binds each context to its
Countdown creation identity. Recycled numeric IDs cannot adopt old children.
The original records and retained media remain available. After new segments,
the exact saved intro/outro and new final export need review and acceptance.
The queued result uses immutable retained source bindings described in
[QUEUED_STUDIO_SOURCES.md](QUEUED_STUDIO_SOURCES.md).

## Admission beyond the interface

Confirm, make, resume, bookend review, narration/render admission and scheduler
recovery require the current contract. Paused legacy research/render is stopped
before automatic replacement or more spending; new empty research remains
eligible to run. A live parent lease is not superseded by recovery.

Direct Studio/residential stage execution also checks its parent before undo or
paid work, while holding the parent source path. It requires exact parent
creation identity, canonical entry and context membership. Initial gather uses
the retained category record; later stages compare that child's gathered facts.
Other children can still be ungathered. Final parent admission checks every
segment. Old unconfirmed child links cannot bypass the parent by opening Studio
directly. Ordinary independently owned LongForm work keeps its separate flow.

**From breakdowns** creates an unconfirmed title draft, with no copied narration
or adoption of another campaign's media. Confirmation still requires exact
counts, ranking rationale and category evidence.

Automation proceeds only with a complete supported ranking. Incomplete or
unsupported rankings keep every entry and the requested format for owner review.
Candidate titles cannot automatically fill gaps, remove unmatched entries,
truncate/reorder the list, invent ranking reasons or shrink a Top10 to Top5.
Even an automatic valid list waits for intro/outro and final export acceptance.

The historical queue source label **Countdown Studio** is recognized alongside
**Countdowns Studio**. Unbound legacy rows cannot be treated as ordinary manual
media to bypass reviewed-source admission.

parent lease is preserved before stopped-work recovery. Immutable export inputs
and the final fingerprint retain requested format. Acceptance records that exact
format; retained dispatch requires explicit format/count/acceptance proof and
never infers it from a changed live draft. Older formatless exports need current
review/resend. The interface displays the format and explains supported recovery.
