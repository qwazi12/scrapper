4. Run the full backend suite (897+ tests) and the frontend type-check + node tests.
5. Commit one step per commit with a clear message; push to `main` (Railway + Vercel deploy from `main`).
   Push only when Studio is idle (a deploy restarts the server and interrupts a running job).
6. Verify on the live site (API and the owner's Chrome) and record the evidence in MEMORY.md.
7. Rollback for any step: `git revert <sha>` and push; settings changes are undone in Settings / via the API.

## Step 1 — Unblock the 20 finished LongForm videos (critical: no new LongForm can reach the queue)
Three separate causes; all three must be fixed.

### 1a. Old renders have no quality inspection
- Cause: renders made before the 0e5e500 release have no `render.quality` (schema 1). `export_fingerprint()`
  (`backend/app/studio/media_quality.py`) refuses them with "Inspect this final export before approval"; the
  ✓ Approve button is greyed (`StudioPanel.tsx`, `disabled={… || !r.quality …}`) with no explanation and no
  way to inspect except a full re-render.
- Fix:
  - New route `POST /api/studio/projects/{id}/inspect` (and `/api/countdowns/{id}/inspect`) that runs the
    existing `inspect_export()` on the existing final file and saves `render.quality`. No re-render, no AI cost.
  - A one-time backfill job that inspects every rendered-but-uninspected project (about 20) and logs the result.
  - UI: when inspection is missing, show "🔍 Run inspection" next to ✓ Approve with one line explaining why.
- Tests: route inspects a real tiny ffmpeg file and saves schema-1 quality; backfill skips already-inspected ones.
- Done when: all 20 show "decoded" and ✓ Approve is enabled (or shows a real finding).

### 1b. Bulk "Send to queue" has no approval step
- Cause: `publish_batch` (`backend/app/studio/routes.py`, ~line 862) calls the same send that now requires an
  approval per video; the bulk bar has no approve action, so "Sent 0 of 20".
- Fix: bulk "✓ Approve & send" applies the one-tap approval rules (`export_acceptance.quick_accept`) to each
  selected video, then sends it. Serious findings (black > 3 s, silence > 8 s, length off by half/double)
  are listed and skipped, never approved silently. Needs the owner's saved rights statement (owner decision D1).
- Tests: bulk approve+send sends clean ones, skips serious ones with the reason, refuses without a rights statement.
- Done when: the 20 videos go to the LongForm queue in one action, except any with real findings.

### 1c. Credit check false positives
- Cause: `research_gate.structured_conflicts` / `_credit_value` / `_forward_performer_conflicts` /
  `_writing_conflicts` accept only the exact role right after "as" / "voiced by". Extra words ("…sharing a
  passionate embrace", "…for another wild ride", "Lord Lovat Simon Fraser" vs "Lord Lovat (Simon Fraser)",
  "voiced by Hailee Steinfeld, suddenly…", "co-wrote the screenplay alongside…") are reported as conflicts.
- Fix: flag only a real contradiction —
  - an actor named with a role that belongs to a different credited actor, or
  - a known role attributed to a different actor, or
  - a writing claim that names someone credited for a different job.
  Unknown or extra words are never a conflict. Parentheses/brackets in credits are normalised.
- Tests (regression fixtures from today's live data): Outlander S11/S12/S16, Jailer 2 S4, Hexed "voiced by",
  Sacrifice S4, Wicker "a lonely fisherwoman" all pass; "Robert Pattinson plays Feyd-Rautha" (Austin Butler's
  role) and "Olivia Colman stars as a lonely lighthouse keeper"-style true mismatches still blocked.
- Done when: re-checking the 20 projects shows no false conflicts.
